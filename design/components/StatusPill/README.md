# StatusPill

A state as a dot and a word: Conned, Learning, Immune, Served or Open.

**Props:** `state` conned | learning | immune | served | idle; `label` (override); `detail` (such as "in 0.8s"); `size` sm | md | lg | stage; `solid` (adds a quiet glass pill).

- The word carries the meaning; the colour only confirms it.
- When the state changes the word blurs across and the dot pings once.
- Only for store and test states.
