# Ticker

A number that counts from its last value to the new one, in tabular figures.

**Props:** `value`; `format` int | money | percent | seconds | decimal; `from` (first render); `duration` (default `dur-tick`); `prefix`, `suffix`.

- Use it for every number that changes on screen: money lost, cons blocked, shoppers, the rollout time.
- With reduced motion it jumps straight to the value.
