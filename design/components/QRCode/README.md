# QRCode

A QR code from a module matrix: navy on paper with a 4-module quiet zone.

**Props:** `rows` (strings of 0 and 1); `size`; `title`.

- Generate the matrix with any QR library at error correction M. Keep URLs short (version 2, 25 modules).
- Never tint the modules or set the code straight on glass: it always sits on paper.
