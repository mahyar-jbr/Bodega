# Logo

The Bodega logo: the awning mark beside the lowercase wordmark.

**Props:** `variant` lockup | stacked | mark | wordmark; `height` (px, rendered height); `title` (accessible name, default "Bodega").

- The mark is `brand-ink` (Signal Green on Stage, forest green in Daylight); the wordmark is `ink`. Both follow the theme.
- Lockup by default, stacked for centred or square layouts, the mark alone at 32px and under.
- Keep clear space equal to the mark's height on every side. Never stretch it, outline it, add effects or draw the mark in a store colour.
