# AwningMark

The awning mark on its own: five slanted stripes, rounded at the hem, in one colour.

**Props:** `store` brand | queen | yonge | scarborough; `width` (px); `title`.

- `store="brand"` is the logo mark. A store key draws it in that store's colour: the store's avatar and sign.
- Smallest size 14px wide. On the receipt it prints in `paper-ink`.
