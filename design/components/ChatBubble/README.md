# ChatBubble

A chat message: the shopkeeper speaks in plain text beside its awning mark; the customer's words sit in a quiet bubble on the right.

**Props:** `from` shopkeeper | customer; `store`; `tone` refusal | conned; `time`; `attachment` (RefusalCard, ConLanded); children.

- Show the time on the last message of a run only.
- Codes inside messages use Code.
