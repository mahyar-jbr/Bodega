# Icon

One of 64 line icons drawn for Bodega on a 24px grid with a 1.6 stroke.

**Props:** `name`; `size` (px, default 24); `strokeWidth`; `title` (makes it an image with a name; otherwise decorative).

- Inherits `currentColor`. Beside text it sits in `ink-3`; it takes a state colour only inside a state element (the refusal note, the verdict).
- Fixed meanings: mask is a con, loop is learning, shield-check is a block, bag-check is a sale, flask is the test, scale is the rule for shipping.
- Icon-only buttons need a label.
