# Stores

- `awning-queen.svg`, `awning-yonge.svg`, `awning-scarborough.svg`: each store's awning mark in its colour, for dark grounds. Use it as the store's avatar and sign.
- `store-<key>-stage.svg`, `store-<key>-daylight.svg`: the store sign, its mark beside the store name, outlined. Stage for dark grounds (near-white name), Daylight for light grounds (navy name, deeper store colour).
