# Logos

Outlined vector logos; no font needed. The mark is one colour: Signal Green (#00ED64) in the Stage files for dark grounds, forest green (#00684A) in the Daylight files for light grounds. The wordmark is near-white (#EEF2F1) on Stage and navy (#0B1A21) in Daylight.

- `bodega-lockup-stage.svg`, `bodega-lockup-daylight.svg`: the default lockup, the awning mark beside the wordmark.
- `bodega-stacked-stage.svg`, `bodega-stacked-daylight.svg`: the mark above the wordmark, for square and centred layouts.
- `bodega-mark-stage.svg`, `bodega-mark-daylight.svg`: the awning mark alone (favicons, avatars, 32px and under).
- `bodega-wordmark-stage.svg`, `bodega-wordmark-daylight.svg`: the wordmark alone, when the mark already appears nearby.
- `bodega-app-icon.svg`: the 1024 app icon, the green mark on navy with the light from above. A PNG is in Exports.

Clear space is the mark's height on every side. Never draw the logo mark in a store colour.
