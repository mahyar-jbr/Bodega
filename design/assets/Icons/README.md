# Icons

64 line icons drawn for Bodega on a 24px grid: 1.6 stroke, round caps and joins, 2px padding. One ink, slate #6B7F8A, so the files read on light and dark grounds. In code use the `Icon` component, which inherits `currentColor`; recolour the files only by editing their stroke and fill.

Three families: interface (check to user-check), Bodega ideas (store to bolt) and the twelve products (coffee to console).
